# Stabilizers

A core will not activate without Stabilizers. Place four of them in a cross around the core, all on the same plane (horizontal or vertical), each one in line with the core and within 16 blocks of it.

From tier 5 up each of the four must be an **advanced stabilizer**: nine Stabilizers placed as a flat 3x3 square facing the core.

<Recipe id="draconicevolution:machines/energy_core_stabilizer" />

Right-clicking a linked Stabilizer opens the core's screen, which tells you if the structure or the stabilizers are wrong.
