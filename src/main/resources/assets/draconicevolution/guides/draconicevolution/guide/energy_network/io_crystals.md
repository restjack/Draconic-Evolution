# Energy I/O Crystals

An I/O crystal attaches to the face of the block you place it on: a machine, a cable, a generator or a pylon. **Shift-right-click** it with an empty hand to switch mode:
- Input from Block: accepts energy the block pushes into it. Use this on generators and on pylons set to output.
- Output to Block: pushes network energy into the block.

An input crystal does not pull. The block it sits on has to push energy out.

## Links

- Basic: 2 links
- Wyvern: 3 links
- Draconic: 4 links

With so few links, I/O crystals are usually linked to a relay crystal rather than to each other.

One relay crystal crafts into two I/O crystals of the same tier, and two I/O crystals craft back into one relay.
