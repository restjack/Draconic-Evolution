# Injectors

Injectors hold the ingredients of a fusion recipe, one stack each. There are four tiers:
- **Draconium** (basic)
- **Wyvern**
- **Draconic**
- **Chaotic**

Every recipe has a tier, shown in JEI. **Every injector that holds an item** must be that tier or higher, or the core reports that the injector tier is too low. Lower-tier injectors can stay in the setup as long as they are empty.

Higher tiers also charge and craft faster.

## Using injectors

Right-click an injector with an item to insert it; right-click again with an empty hand to take it back.

**Shift-right-click** with an empty hand toggles **single item mode**. In that mode the injector accepts only one item, which stops automation from overfilling it. Stack mode is the default.

## Upgrading

The Chaotic injector uses a **Dragon Egg** and Large Chaos Fragments from the [Chaos Guardian](../endgame/chaos_guardian.md). Each tier is made from the one below it, so you need at least one injector of a tier before you can make the next one.
