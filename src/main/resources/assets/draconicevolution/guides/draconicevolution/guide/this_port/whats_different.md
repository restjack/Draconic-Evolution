# What's Different in This Port

Draconic Evolution has no official release for Minecraft 26.1. This server runs an unofficial community port of DE 3.1.4 with extra fixes and features added for this pack.

Most blocks and items work as in the official mod. A few systems have **not been tested** here yet, so treat them with care and keep backups.

## Untested

- The [Draconic Reactor](../endgame/reactor.md). Try it in a copy of the world first.
- The [Chaos Guardian](../endgame/chaos_guardian.md) fight. Back up before fighting.
- Modular tools and armour in heavy combat.
- Dislocators and portals.

If something breaks, tell the server admin what you did and when.

## On this server

- Draconium ore in the Overworld is rare; the End is the main source. Chunks generated before DE was added got ore afterwards.
- The End and Nether were reset so they contain DE ore and Chaos Islands. Islands sit inside the End border.
- **Never move an Energy Core with AE2 Spatial IO.** Core blocks refuse to be moved for that reason.

## Added in this port

- Jade tooltips for the core, pylons and stabilizers.
- Core screen shows in, out, net and time to full or empty.
- Pylons say their mode when toggled and are coloured green (input) or red (output).
- An eye button to hide core effects, plus a render-distance setting.
- DE machines push energy straight into cables such as Powah's.
- This guide. The Information Tablet opens it too.

## Known quirks

- The core screen used to show only the net rate; Shift is no longer needed.
- Pylons do nothing while the core is inactive: check the core's power button first.
- The Information Tablet has no recipe, as in the official mod; craft this book from a Book and Draconium Dust instead.
