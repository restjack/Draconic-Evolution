# Modular Tools

Pickaxe, shovel, axe, hoe, sword and bow come in Wyvern, Draconic and Chaotic tiers. Each tier mines faster and hits harder than the last, but all of them depend on [modules](../equipment/modules.md) and stored energy.

Which modules fit depends on the tool: pickaxe and shovel take mining modules, the sword takes weapon modules, the axe takes both plus Tree Harvest, the hoe takes AOE, and the bow takes projectile modules.

## Staff of Power

The **Staff of Power** (Draconic and Chaotic only) is a pickaxe, shovel, axe and sword in one, with a much bigger module grid. It is made from the matching pickaxe, shovel and sword.

Tool Config (**C**) sets mining speed, AOE size and similar options, so a big AOE tool can still dig a single block.

## Capacitors

A **Capacitor** is a portable battery. It stores nothing until you add energy modules. In Tool Config, choose what it charges: the held item, worn armour, the hotbar, the main inventory, and Curios slots when Curios is installed.

## Recipes

Tools are made by [Fusion Crafting](../fusion_crafting/overview.md). The Wyvern tool uses the vanilla diamond tool as its catalyst; each higher tier uses the tier below. The pickaxe line is shown here; every other tool follows the same pattern, so look the rest up in JEI.
