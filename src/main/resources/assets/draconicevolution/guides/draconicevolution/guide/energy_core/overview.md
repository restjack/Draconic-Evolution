# The Energy Core

The **Energy Core** is a multiblock energy store. It starts as a single block and grows into a large sphere of Draconium and Redstone blocks as you raise its tier.

Energy goes in and out through [Energy Pylons](../energy_core/pylons.md), and the core only works while it is held in place by [Stabilizers](../energy_core/stabilizers.md).

<Recipe id="draconicevolution:machines/energy_core" />

Start here: place the core where the middle of the finished build should be.

Energy is measured in OP, which converts 1:1 with FE.

## Capacity

- Tier 1: 45.5 million OP
- Tier 2: 273 million OP
- Tier 3: 1.64 billion OP
- Tier 4: 9.88 billion OP
- Tier 5: 59.3 billion OP
- Tier 6: 356 billion OP
- Tier 7: 2.14 trillion OP
- Tier 8: effectively unlimited OP

Tier 8 has no practical limit; its screen lets you set an energy target just for display. Server owners can change these numbers in the DE config.
