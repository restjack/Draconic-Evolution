# Building a Core

- Place the **Energy Core** and right-click it.
- Use **Tier Up / Tier Down** to pick a tier.
- Press **Toggle Build Guide** to see a hologram of every block you need.
- Place the blocks, or press **Assemble Core** to let the core place them from your inventory.
- Turn the build guide off, add [Stabilizers](../energy_core/stabilizers.md), then press **Activate**.

## Blocks per tier

- Tier 1: just the core
- Tier 2: 6 Draconium
- Tier 3: 26 Draconium
- Tier 4: 54 Draconium, 26 Redstone
- Tier 5: 90 Draconium, 80 Redstone
- Tier 6: 150 Draconium, 178 Redstone
- Tier 7: 210 Draconium, 328 Redstone
- Tier 8: 786 Draconium, 378 Awakened Draconium

All of these are storage blocks; any Draconium or Redstone block tagged as such works.
