# Draconic Evolution Guide

A field guide to Draconic Evolution on Minecraft 26.1.2.

This book was written for the unofficial 26.1.2 port. Some features are untested here, so read [What's different in this port](../this_port/whats_different.md) before you build anything big.

Recipes for every item are also in JEI. The same guide opens as a wiki-style GuideME page: hold G while hovering a Draconic Evolution item.
