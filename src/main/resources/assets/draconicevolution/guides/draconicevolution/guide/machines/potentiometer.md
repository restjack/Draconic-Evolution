# Potentiometer

A small plate that gives off an adjustable redstone signal from 0 to 15. It can be placed on any side of a solid block.


- Right-click: signal +1 (after 15 it wraps to 0).
- Shift-right-click: signal -1 (after 0 it wraps to 15).

<Recipe id="draconicevolution:machines/potentiometer" />

The current value appears above the hotbar. It also powers the block it sits on.
