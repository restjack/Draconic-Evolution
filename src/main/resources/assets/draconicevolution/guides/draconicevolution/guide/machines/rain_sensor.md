# Rain Sensor

A flat sensor that gives a full-strength redstone signal while it is raining, as long as it can see the sky. It checks once per second. Red particles show when it is on.

Pair it with a [Celestial Manipulator](../machines/celestial_manipulator.md) to clear the weather as soon as rain starts.
